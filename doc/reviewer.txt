================================================================================
1. INTRODUCTION                                      *reviewer-introduction*

reviewer.nvim is a stripped-down, branch-scoped review layer for
codediff.nvim. Leave inline comments on a diff, then send them all to
sidekick.nvim in one keystroke.

Features:
- Inline comments on diff lines, with a floating input popup
- File-level comments
- Comments stored per repository and branch
- Send every comment to sidekick.nvim as markdown, then clear them

================================================================================
2. REQUIREMENTS                                      *reviewer-requirements*

- Neovim >= 0.10
- codediff.nvim
- sidekick.nvim (only for sending)

No other UI dependency: the comment popup is a plain floating window.

================================================================================
3. INSTALLATION                                    *reviewer-installation*

With lazy.nvim: >lua
  {
    "you/reviewer.nvim",
    dependencies = {
      "esmuellert/codediff.nvim",
      { "folke/sidekick.nvim", optional = true },
    },
    event = "VeryLazy",
    opts = {},
  }
<
Load the plugin before you open codediff (VeryLazy or lazy = false). The keys
are buffer-local to the codediff panes. reviewer.nvim follows the current
codediff tab: keys, marks, and comments apply to the active tab's session.

sidekick.nvim is optional and loaded on demand: it is only required when you
press `S`. The `optional = true` entry lets lazy.nvim load it when `S` requires
it without force-loading it at startup.

Options: >lua
  opts = {
    sidekick = {
      -- sidekick tool that receives the comments; nil = sidekick's current tool
      tool = "copilot",
    },
  }
<

================================================================================
4. KEYMAPS                                              *reviewer-keymaps*

In a codediff diff: >text
  i        Add a comment at the cursor line
  F        Add or edit a file-level comment
  e        Edit the comment at the cursor
  d        Delete the comment at the cursor
  c        List all comments and jump to one
  ]n       Next comment
  [n       Previous comment
  S        Send all comments to sidekick, then clear them
  q        Clear comments and close the review tab
<
Comment popup: |<C-s>| submits, |<Esc>| or |q| cancels.

================================================================================
5. STORAGE                                              *reviewer-storage*

One JSON store per repository and branch, in
`~/.local/share/nvim/reviewer/<repo>-<branch>.json`. Comments on one branch
never show on another.

================================================================================
6. SENDING TO SIDEKICK                                    *reviewer-send*

|S| sends a markdown list, one line per comment: >text
  Code review comments on the current diff (`file:line`, `~` = old side).

  1. `src/api.ts:23` - endpoint does not handle errors
  2. `src/utils.ts:~10` - old implementation was cleaner
  3. `src/api.ts` - whole file needs a pass
<
A `~` before the line number marks the old (left) side of the diff. A bare path
is a file-level comment. Multi-line comments are flattened to one line. After
sending, all comments and their inline marks are removed.
